# ConnectSphere 🎥

ConnectSphere is a modern full-stack video conferencing platform that enables users to communicate and collaborate in real time through high-quality video and audio meetings.

## 🚀 Features

- 🔐 User Authentication (JWT/OAuth)
- 🎥 Real-Time Video & Audio Calls
- 💬 Live Chat Messaging
- 🖥️ Screen Sharing
- 👥 Meeting Rooms
- 📅 Meeting Scheduling
- 🎙️ Noise Cancellation Support
- 📝 Live Captions
- 📂 File Sharing
- 🎬 Meeting Recording
- 🌐 Responsive UI for Desktop & Mobile

---

## 🛠️ Tech Stack

### Frontend
- React.js / Next.js
- Tailwind CSS
- Socket.IO Client

### Backend
- Node.js
- Express.js
- Socket.IO
- WebRTC

### Database
- MongoDB

### Authentication
- JWT Authentication
- OAuth 2.0

### Deployment
- Docker
- Vercel / AWS / Render
